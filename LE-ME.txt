# Operação Natal — experiência multimédia

Inclui a página inicial, a capa ilustrada, o dossier PDF e a banda sonora através do leitor oficial do YouTube.

## Música
A faixa escolhida é “All I Want for Christmas Is You”, de Mariah Carey, reproduzida pelo YouTube (ID do vídeo: aAkMkVFwAoo). A reprodução é solicitada quando o destinatário carrega em **INICIAR OPERAÇÃO**. Os navegadores bloqueiam normalmente áudio automático antes de uma interação do utilizador; em alguns dispositivos o YouTube poderá ainda exigir que se carregue em Play no próprio leitor.

A música não está descarregada nem incorporada no ZIP: é reproduzida pelo YouTube, respeitando os direitos de autor e os controlos da plataforma.

## Publicar a atualização no GitHub Pages
1. Extrai o ZIP.
2. No repositório GitHub `operacao-natal`, abre **Add file → Upload files**.
3. Carrega os ficheiros atualizados `index.html`, `operacao-natal-capa.png`, `dossier-operacao-natal.pdf` e `LE-ME.txt`.
4. Confirma que os ficheiros ficam na raiz do repositório.
5. Escolhe **Commit changes**. Se o GitHub perguntar se quer substituir `index.html` e os restantes ficheiros, confirma.

O GitHub Pages publica a atualização automaticamente após alguns minutos.
