# Operação Natal — experiência multimédia

## Ficheiros
- `index.html` — página da experiência.
- `operacao-natal-banda-sonora.mp3` — banda sonora instrumental original, criada para a Operação Natal.
- `operacao-natal-capa.png` — imagem de ambiente natalício.
- `dossier-operacao-natal.pdf` — dossier final em PDF.
- `LE-ME.txt` — estas instruções.

## Música
A banda sonora é uma composição instrumental original, com ambiente cinematográfico natalício, metais, cordas, sinos e percussão. Tem cerca de 38 segundos e repete em loop. O ficheiro MP3 está incluído no repositório, por isso não há anúncios, YouTube ou serviços externos.

A reprodução começa no primeiro clique em **INICIAR OPERAÇÃO**. Os navegadores podem bloquear áudio automático antes de uma interação do utilizador; por isso, o clique de início autoriza a reprodução. Se o dispositivo ainda bloquear, aparece um botão para iniciar a música manualmente.

## Atualizar o GitHub Pages
1. Extrai o ZIP.
2. No repositório `operacao-natal`, abre **Add file → Upload files**.
3. Carrega os ficheiros `index.html`, `operacao-natal-banda-sonora.mp3`, `operacao-natal-capa.png`, `dossier-operacao-natal.pdf` e `LE-ME.txt` para a raiz.
4. Confirma que os nomes ficam exatamente iguais.
5. Clica em **Commit changes**.

O GitHub Pages publica a atualização automaticamente após alguns minutos.
